How to read this view

Each pair counts orders containing both categories. This can help shape product bundles, cross-sell placements and campaign ideas. Association does not prove that one item caused the other to be purchased.

This prototype calculates category-level co-occurrence. A production extension could add support, confidence and lift for formal association-rule mining.
